# 프로젝트

> **학습 노트를 실제 코드로 옮기는 곳.** 노트에서 정리한 개념을 하나의 프로젝트 안에서 직접 구현하고, 문제를 재현하고, 수치로 확인한다.

CS 노트는 "면접에서 설명할 수 있는가", 인프라 노트는 "직접 돌려 봤는가"가 목표다.
이 트리는 둘을 **한 프로젝트로 묶어 이력서에 올릴 결과물을 만드는 계획**을 둔다.
계획의 각 단계는 그 단계에서 읽어야 할 CS · 인프라 노트의 절로 바로 연결된다.

| 구분 | CS 노트 | 인프라 노트 | 프로젝트 |
| -- | -- | -- | -- |
| **목적** | 면접에서 설명하기 | 직접 돌려 보고 다시 찾아보기 | 개념을 코드로 옮겨 포트폴리오 만들기 |
| **단위** | 주제 하나 | 설치 · 설정 하나 | 프로젝트 하나 (일정 + 단계별 구현 가이드) |
